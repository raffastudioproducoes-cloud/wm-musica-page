# Override de página — Dashboard

## Escopo

Este override é reservado exclusivamente para uma página futura chamada `dashboard`. Ele não se aplica à landing page institucional de Wilma Machado.

## Regras específicas

- Reutilizar integralmente os tokens de cor, tipografia, borda, foco e motion do master global.
- Priorizar legibilidade, agrupamento semântico e hierarquia de conteúdo; não introduzir visual SaaS genérico, dark mode, novos gráficos, novos ícones ou novas cores.
- Usar layout responsivo de uma coluna em mobile e grades apenas quando houver conteúdo confirmado.
- Estados de carregamento, vazio, erro e indisponibilidade devem ser explícitos e acessíveis.
- Não usar dados, métricas, gráficos, filtros ou ações simuladas. Se o conteúdo não existir, renderizar estado honesto ou omitir o módulo.

## Fora de escopo

Este arquivo não aprova ativos, fontes, tokens ou componentes novos e não autoriza alterar a landing page institucional.
